# FitLog 🏋️‍♂️

FitLog is a dark, no-nonsense gym companion web application built with **Next.js**, **TypeScript**, and **Tailwind CSS**. It allows users to browse a comprehensive workout library, manage their daily workout plans, save favorite exercises, and track their fitness progress effortlessly.

## 🚀 Features

- **Workout Library:** Explore a variety of lifts covering major muscle groups.
- **Plan & Save Management:** Add workouts to today's plan or save them for later using browser local storage.
- **Responsive Design:** Fully optimized for both mobile and desktop views with a sleek dark UI.
- **Interactive UI:** Dynamic counters, smooth navigation, and active state tracking.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** LocalStorage API & Custom Events
